### 🎯 Objetivo

O principal objetivo desta disciplina é compreender e aplicar conceitos de modelagem e programação para bancos de dados NoSQL orientados a documentos, com foco em:

* Modelagem flexível baseada em embutimento (*embedding*) e referências.
* Manipulação avançada de arrays (`$push`, `$each`, `$pull`, `$set`).
* Tratamento e consistência de tipos de dados (padronização de strings para identificadores como CNPJs e telefones).
* Cruzamento de dados entre coleções utilizando o Pipeline de Agregação (`aggregate` e `$lookup`).

### 🛠️ Tecnologias Utilizadas

* **MongoDB** (NoSQL / Orientado a Documentos).
* **NoSQLBooster for MongoDB** (IDE de gerenciamento e execução de scripts).
* **MongoDB Shell / Compass**.
* **JavaScript** (para estruturação de queries e comandos).
